# Android-Tg-Ws-Proxy

Локальный MTProto-прокси для Android, перенаправляющий трафик Telegram через WebSocket-соединения. Приложение работает автономно на устройстве, без использования сторонних серверов.

## Как это работает

1. Приложение запускает локальный MTProto-прокси на устройстве (`127.0.0.1`).
2. Перехватывает подключения от клиента Telegram и определяет нужный дата-центр (DC).
3. Устанавливает прямое защищённое WebSocket-соединение к серверам Telegram (с автоматическим откатом на резервный маршрут при недоступности WS).

## Быстрый старт

1. Откройте приложение и нажмите **«Старт»** для запуска фонового прокси-сервера.
2. Нажмите кнопку подключения (или скопируйте прокси-ссылку `tg://proxy`) и подтвердите добавление прокси в Telegram.
3. При необходимости добавьте приложение в исключения энергосбережения Android, чтобы система не останавливала сервис в фоне.
